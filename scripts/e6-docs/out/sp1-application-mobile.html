Intitulé de la situation professionnelle

Développement d'une application mobile e-commerce connectée à PrestaShop.

Période de réalisation : 2025 – 2027  ·  Lieu : Librairie Sana — Paris (75011)

Contexte

L'entreprise développe son activité e-commerce et souhaite proposer une application mobile connectée à sa boutique PrestaShop. L'objectif est de rendre le catalogue et le suivi des commandes accessibles depuis un smartphone, tout en conservant la synchronisation avec la base de données de la boutique.

Besoin

Concevoir une application mobile cross-platform permettant de consulter les produits, de gérer un panier, de passer commande et de suivre les commandes. L'application doit s'appuyer sur les API REST de PrestaShop et sur les données de la boutique.

Utilisateurs concernés

  • Client : consulter le catalogue, rechercher un produit, gérer son panier, passer commande et suivre sa commande.
  • Équipe interne : consulter les données, suivre les commandes et disposer d'un outil connecté au système e-commerce.

Contraintes techniques

  • Application cross-platform en Flutter/Dart.
  • Connexion aux API REST de PrestaShop.
  • Base de données MySQL et phpMyAdmin.
  • Services mobiles Firebase ; environnement Linux/Bash et PuTTY.

Compétences travaillées

  • Concevoir et développer une solution applicative.
  • Gérer les données d'une application.
  • Assurer la maintenance corrective ou évolutive d'une solution applicative.

Conditions de réalisation (ressources fournies, résultats attendus)

  • Accès à la boutique PrestaShop et à sa base de données de test (MySQL, phpMyAdmin).
  • Documentation de l'API REST PrestaShop, maquettes et spécifications fonctionnelles.
  • Environnement de développement Flutter / Android Studio.
  • Application mobile fonctionnelle, connectée à l'API, avec catalogue, panier, commande et suivi ; code source et documentation livrés.

Description des ressources documentaires, matérielles et logicielles utilisées

Documentaires : documentation PrestaShop et API REST, maquettes, MCD/MLD, spécifications fonctionnelles, documentation Flutter et Dart.

Matérielles : PC de développement, smartphone Android, émulateur, serveur de la boutique PrestaShop.

Logicielles : Flutter, Dart, Android Studio, VS Code, MySQL, phpMyAdmin, Firebase, Git, PuTTY, Linux/Bash.
