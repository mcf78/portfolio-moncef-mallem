Application mobile e-commerce connectée à PrestaShop

Centre de formationParis Ynov Campus — Nanterre

Période2025 – 2027

Organisation support

Librairie Sana est une SARL spécialisée dans la vente de livres religieux et de produits culturels. Elle dispose d'un site e-commerce PrestaShop en production, d'un dépôt logistique, d'un service après-vente et de pôles internes de création graphique.

Contexte

L'entreprise développe son activité e-commerce et souhaite proposer une application mobile connectée à sa boutique PrestaShop. L'objectif est de rendre le catalogue et le suivi des commandes accessibles depuis un smartphone, tout en conservant la synchronisation avec la base de données de la boutique.

Besoin

Concevoir une application mobile cross-platform permettant de consulter les produits, de gérer un panier, de passer commande et de suivre les commandes. L'application doit s'appuyer sur les API REST de PrestaShop et sur les données de la boutique.

Utilisateurs

  • Client : consulter le catalogue, rechercher un produit, gérer son panier, passer commande et suivre sa commande.
  • Équipe interne : consulter les données, suivre les commandes et disposer d'un outil connecté au système e-commerce.

Contraintes techniques

  • Application cross-platform en Flutter/Dart.
  • Connexion aux API REST de PrestaShop.
  • Base de données MySQL et phpMyAdmin.
  • Services mobiles Firebase.
  • Environnement Linux/Bash et PuTTY.

Résultats attendus

Une application fonctionnelle sur Android et iOS, connectée à l'API, avec un parcours d'achat et un suivi des commandes. Le code source, les maquettes, les tests et la documentation sont disponibles.

Compétences mobilisées

Concevoir et développer une solution applicative Gérer les données d'une application Assurer la maintenance corrective et évolutive Travailler en mode projet

Livrables

  • Maquettes des écrans et parcours utilisateurs.
  • Application Flutter et intégration de l'API REST.
  • Base de données de test et jeu de tests.
  • Documentation technique et captures d'écran.
