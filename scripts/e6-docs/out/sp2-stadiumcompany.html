Organisation support de la situation professionnelle

Le projet est réalisé dans le cadre de la formation BTS SIO SLAM. StadiumCompany est une organisation de support pédagogique qui gère un grand stade multi-événements (matchs, concerts, spectacles). Elle édite un site web officiel présentant ses événements, sa billetterie en ligne et son espace administrateur.

Intitulé de la situation professionnelle

Conception et développement du site web officiel de StadiumCompany.

Période de réalisation : 2026 – 2027  ·  Lieu : Ynov Campus Paris

Contexte

La gestion des événements et des réservations est réalisée manuellement. L'organisation souhaite un site web officiel pour présenter les événements, centraliser les informations et permettre la réservation en ligne.

Besoin

Créer un site web responsive avec une partie publique (événements, billetterie, réservation, boutique, restauration, contact) et un espace administrateur pour gérer les événements, les places et les réservations.

Utilisateurs concernés

  • Visiteur / client : consulter les événements, vérifier les places disponibles et réserver.
  • Administrateur : gérer les événements, les places et les réservations depuis le back-office.

Contraintes techniques

  • HTML5, CSS3, Bootstrap 5 et JavaScript.
  • PHP et PDO pour le traitement serveur.
  • MySQL/MariaDB pour les données.
  • Déploiement Apache2 sur VM Debian ; site responsive et sécurisé.

Compétences travaillées

  • Concevoir et développer une solution applicative.
  • Gérer les données d'une application.
  • Assurer la maintenance corrective ou évolutive d'une solution applicative.

Conditions de réalisation (ressources fournies, résultats attendus)

  • Cahier des charges, spécifications fonctionnelles, maquettes et MCD/MPD.
  • Environnement PHP/MySQL et VM Debian.
  • Documentation Bootstrap, PHP, PDO et MySQL.
  • Site responsive avec pages publiques, espace administrateur protégé, base opérationnelle, tests et documentation livrés.

Description des ressources documentaires, matérielles et logicielles utilisées

Documentaires : cahier des charges, wireframes, MCD/MPD, spécifications fonctionnelles, documentation Bootstrap, PHP, PDO et MySQL.

Matérielles : PC, VM Debian, serveur web Apache2, base de données MySQL/MariaDB.

Logicielles : VS Code, XAMPP, MySQL/MariaDB, phpMyAdmin, Git, MobaXterm, navigateur web.
