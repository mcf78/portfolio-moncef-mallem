Organisation support

StadiumCompany est une organisation fictive qui gère un grand stade multi-événements : matchs, concerts et spectacles. Le projet est réalisé dans le cadre de la formation BTS SIO SLAM.

Contexte

La gestion des événements et des réservations est réalisée manuellement. L'organisation souhaite un site web officiel pour présenter les événements, centraliser les informations et permettre la réservation en ligne.

Besoin

Créer un site web responsive avec une partie publique (événements, billetterie, réservation, boutique, restauration, contact) et un espace administrateur pour gérer les événements, les places et les réservations.

Utilisateurs

  • Visiteur / client : consulter les événements, vérifier les places disponibles et réserver.
  • Administrateur : gérer les événements, les places et les réservations depuis le back-office.

Contraintes techniques

  • HTML5, CSS3, Bootstrap 5 et JavaScript.
  • PHP et PDO pour le traitement serveur.
  • MySQL/MariaDB pour les données.
  • Déploiement Apache2 sur VM Debian.
  • Site responsive et sécurisé.

Résultats attendus

Un site fonctionnel avec les pages publiques, une base de données opérationnelle, un espace administrateur protégé, des tests et une documentation.

Compétences mobilisées

Concevoir et développer une solution applicative Gérer les données d'une application Assurer la maintenance corrective et évolutive Travailler en mode projet

Livrables

  • Wireframes et spécifications fonctionnelles.
  • MCD/MPD et script SQL de création de la base.
  • Code source du site et du back-office.
  • Jeu de tests, captures et documentation.
